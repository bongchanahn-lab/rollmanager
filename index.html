2. Cloud Firestore 규칙(Rules) 읽기/쓰기 허용

Firestore Database 규칙 탭에서 로그인된 클라이언트의 접근이 허용되어 있는지 확인해 주세요: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
